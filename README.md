# 7005SCN--Individual-Research-Project-Alexia-Petrescu
Artefact 1 and 2 for dissertation submission, including prototype file, test files and the policy written the dissertation.

Artefact one is the prototype(prototype.py) made in Python to detected 4 areas of fileless techniques commonly used by attackers. As part of this artefact, the testing done using pytest is shown in all files beginning with "test_". These tests check all of the functions written within prototype.py, testing that the script will show suspicious commands, macros, and changes in UAC values and in start-up folder. The tests also show edge cases. All tests written have been passed.

Artefact two is a prototype's policy, which gives users instructions of setting it up and what outputs mean. The policy goes in depth on parts of the script to make it easier to understand for users, as well as how to further protect sensitive data against attackers.
